# claude-migration — перенос работы между аккаунтами Claude

Прямой миграции между личными аккаунтами Claude нет. Инструмент превращает
официальный экспорт (Настройки → Приватность → Экспорт данных) в пакет,
готовый к загрузке в новый аккаунт: проекты с инструкциями, выжимки знаний,
архив чатов в Markdown, общий список задач и память.

## Шаги
```bash
# 1. Конвертация: чаты -> Markdown, раскладка по проектам, инструкции, инвентарь
python3 migrate.py --inputs conversations-000.zip design_chats-000.zip frames-000.zip --out out/
#    проверка формата на нескольких чатах:  --sample 5

# 2. Выжимки знаний: в каждой папке проекта KNOWLEDGE_<проект>.md и TASKS_<проект>.md
#    (готовит Claude, читая чаты проекта; формат задач: "- [ГГГГ-ММ-ДД] задача — (чат: «…»)")

# 3. Пакет: ALL_TASKS.md, память, START_HERE.html, инструкция, ZIP
python3 build_package.py --out out/ --memory memory/MEMORY_IMPORT.md --zip Claude_перенос.zip
```

## Настройка
- `config/projects.json` — проекты: название, описание, текст инструкций, ключевые слова для раскладки.
- `config/overrides.json` — ручная привязка: `{"<uuid чата>": "<key проекта>", "artifact:<название>": "<key>"}`.

## Ограничения экспорта
- В `conversations.json` нет привязки чатов к проектам и нет `projects.json` — проект определяется по теме.
- Часть чатов (голосовые, с вложениями) экспортируется без текста — для них создаётся заглушка.
- Файлы-вложения не экспортируются, только извлечённый текст документов.

Личные данные (`out/`, `memory/`, `*.zip`) в git не коммитятся.
